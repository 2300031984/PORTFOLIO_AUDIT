# Personal Portfolio

A personal portfolio website for showcasing projects, technical skills, and development experience.

## Tech Stack

- Next.js
- React
- TypeScript (where used in the application)
- CSS and the styling system configured by the project

## Getting Started

### Prerequisites

- Node.js (use a current LTS release)
- npm, which is included with Node.js

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Changes to the application should appear during development.

### Production build

```bash
npm run build
npm run start
```

## Project Structure

The application follows the Next.js project structure already present in this repository. Start with `app/` for routes and page UI, and check `public/` for static assets when those directories are present.

## Development Notes

- Keep project and skill descriptions accurate and up to date.
- Optimize images and provide meaningful alternative text.
- Check responsive layouts at mobile, tablet, and desktop widths.
- Run the production build before submitting substantial changes.

## Deployment

This project can be deployed to a platform that supports Next.js, such as Vercel. Configure deployment settings to match the repository's package scripts and environment requirements.
