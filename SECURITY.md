# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this portfolio website, please report it privately to the repository owner through GitHub rather than publishing exploit details in a public issue.

Include, where possible:

- A concise description of the issue and its potential impact
- The affected page, endpoint, or component
- Reproduction steps that avoid accessing other people's data
- Relevant screenshots or logs with tokens, credentials, and personal information removed

## Responsible Testing

Only test systems and accounts you own or have explicit permission to assess. Do not attempt denial-of-service attacks, access other users' data, or disclose sensitive information publicly.

## Response

Reports will be reviewed as time permits. Please allow a reasonable period for investigation and remediation before public disclosure.
